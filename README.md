# Mohammad - IoT & MATLAB Solutions Consultant

A professional bilingual (Persian/English) portfolio website for technical consulting services.

## Features

- **Bilingual Support**: Full English and Persian (RTL) language support
- **Responsive Design**: Works perfectly on all devices
- **Modern UI**: Premium engineering-focused design
- **SEO Optimized**: Meta tags, Open Graph, and structured data
- **GitHub Pages Ready**: Deploy directly to GitHub Pages
- **No Dependencies**: Pure HTML, CSS, and vanilla JavaScript

## Quick Start

### Local Development

1. Clone the repository
2. Open `index.html` in your browser
3. Or use a local server: `npx serve .`

### GitHub Pages Deployment

1. Push this repository to GitHub
2. Go to Settings > Pages
3. Select source as "main branch" and root folder
4. Your site will be live at `https://yourusername.github.io/repository-name`

## Customization

### Update Contact Information

Edit the following files to add your contact details:
- `index.html` - Footer social links
- `pages/services.html` - Footer social links
- `pages/contact.html` - Contact information and form

### Add Your CV

Place your CV PDF at `assets/Mohammad_CV.pdf` for the download button to work.

### Color Scheme

Colors are defined as CSS variables in `assets/css/style.css`:
- Primary Orange: `#FF7A00`
- Technology Teal: `#2EC4B6`
- Navy backgrounds: `#0B132B`, `#1C2541`, `#243B55`
